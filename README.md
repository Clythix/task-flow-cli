# TaskFlow CLI

A lightweight, professional command-line task management utility built in Python. Designed for developers who prefer managing productivity straight from the terminal.

## Features
* **JSON-backed Persistence:** Lightweight local data storage.
* **Clean Formatting:** Clear CLI status reports and progress tracking.
* **Modular Design:** Easily extensible codebase.

## Installation & Usage
```bash
git clone [https://github.com/Clythix/task-flow-cli.git](https://github.com/Clythix/task-flow-cli.git)
cd task-flow-cli
python3 main.py
